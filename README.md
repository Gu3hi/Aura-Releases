# Aura-Releases

Aura iOS 越狱玻璃效果插件的公开发布仓库。
Official public releases for the Aura iOS jailbreak glass-effects tweak.

- **Bundle ID**: `com.gushi.aura`
- **支持系统 / Supported**: iOS 16 – iOS 17（RootHide / 标准 rootless 双架构）

## 安装 / Installation

在 Releases 页面下载对应架构的 `.deb` 安装包。
Download the `.deb` for your environment from the Releases page.

- `*_iphoneos-arm64e.deb` — RootHide 环境
- `*_iphoneos-arm64.deb` — 标准 rootless 环境

## 激活 / Activation

Aura 需要设备绑定激活码才能使用。安装后打开「设置 → Aura → 查看设备码并激活」获取 24 位设备码。
Aura requires a device-bound activation code. After installing, go to Settings → Aura → View device code & activate to get your 24-character device code.

- 国内用户：15 元 / 激活码
