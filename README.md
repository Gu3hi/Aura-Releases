# Aura-Releases

Aura iOS 17 越狱玻璃效果插件的公开发布仓库。

- **Bundle ID**: `com.gushi.aura`
- **支持**: iOS 17（RootHide / 标准 rootless 双架构）
- **源码**: 私人备份库（不公开）

## 安装

在 Releases 页面下载对应架构的 `.deb` 安装包：

- `*_iphoneos-arm64e.deb` — RootHide 环境
- `*_iphoneos-arm64.deb` — 标准 rootless 环境

## 激活

Aura 需要设备绑定激活码才能使用。安装后打开"设置 → Aura → 查看设备码并激活"获取设备码。
